\# Data Folder



This folder is expected to contain local GEP/OnSSET scenario result files used by ChatOnSSET.



The raw GEP scenario output files are not committed to this GitHub repository because they are publicly available through the upstream energy data platform and can be downloaded separately. Keeping them outside the repository avoids duplicating large public datasets and keeps the codebase lightweight.



The app currently expects Mozambique scenario files with names such as:

mz-3-0\_0\_0\_0\_0\_0.csv

mz-3-0\_0\_0\_0\_1\_1.csv
